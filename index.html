// keep it short

A session plan, on demand.

Not sure how to structure a build session with new people? Toggle a short, no-fluff plan you can run in one sitting. It stays out of the way until you need it.

session_plan.sh
  1. 00:00Say hi.Names, what you each want to build, what "done" looks like today.
  2. 00:10Pick one thing.One feature, one page, one fix. Small enough to finish today.
  3. 00:20Split the work.Divide by task or pair up. Agree how you'll check in.
  4. 01:20Build, heads down.Short check-ins only. Protect the focus time.
  5. 01:50Wrap and show.Demo to each other. Note what's next, even if it's "keep going".
